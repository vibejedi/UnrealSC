# UnrealSC

A work-in-progress Unreal Engine 5 RTS prototype researching faithful Brood War simulation and modern 3D rendering.

> **Status:** Early prototype. Not affiliated with or endorsed by Blizzard Entertainment. No StarCraft game assets, data archives, or OpenBW source are included.

Development occurs on feature branches. See `docs/ARCHITECTURE.md` and `docs/ROADMAP.md` once the initial foundation PR lands.
